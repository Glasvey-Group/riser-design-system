The buyer path on riser.events, from a category listing to a scanned ticket. Recreated from RiserEvents — EventCard, Filter, Pagination, EventDetails, TicketsList and the public organiser and venue pages. The image blocks below are placeholders: see the imagery audit in the foundations.

01 —Category listing
/category/[id] · /category/all-events

Filter, then a four-column card grid, then pagination. The cards' images run full-bleed to the card edge — Events inset them in a 12px-radius container. Card hover takes the hairline to solid ink; nothing lifts and nothing scales.

03 —Ticket selection
components/TicketsList.tsx

Each tier is a TicketCard in buyer mode: price, terms under a dashed rule, a square quantity stepper. The summary is a sticky ink block — the running total is set in mono with tabular figures so it does not jump as the number changes. Sold-out tiers keep their rule and go slate; they are not hidden.
