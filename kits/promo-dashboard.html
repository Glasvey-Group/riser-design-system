UI kit — the Promo Dashboard
Foundations Components Promo kit Buyer kit Marketing kit

Eight screens, recreated from promo.riser.events — every route, field, column, status and empty string taken from the code in src/app/organizer/[slug]/, not invented. The shell is the same on all of them: a sticky navbar with the lockup left and the organiser context right, a drawer behind the menu button, and a 1440px page.

01 —The shell
components/Navbar.tsx · components/Sidebar.tsx

Promo's navbar was a floating pill: fixed, calc(100% − 6rem) wide, 4px radius, a 10px backdrop blur and a 30px shadow. Flat, square and hairline-ruled means a bar that sits on the page. The logo moves centre to left, because left-aligned is the layout rule. The “as {organizer}” string stays — it is the one piece of state the bar carries.

02 —Dashboard home
/organizer/[slug]/page.tsx

WelcomeBanner over the Campaigns grid, then the Manage button — exactly Promo's composition. The greeting was 3xl Anton with 0.2rem tracking and centred text inside a left-aligned flex column; it is now an H1 with the credit balance as a StatCard, which is what the number actually is. The balance is the one orange thing on this screen.
